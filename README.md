# Fundamentals of Linux and Windows

## Overview
This repository contains detailed reports of assignments from HackTheBox Academy on **Linux Fundamentals** and **Windows Fundamentals**. These reports include hands-on challenges, practical scenarios, and theoretical insights designed to deepen understanding of essential concepts within both operating systems.

## Contents
### Linux Fundamentals
- **Shell Commands:** Basic system information commands like `uname`, `id`, and `ifconfig`.
- **Navigation:** Traversing directories and identifying hidden files using `ls`, `pwd`, and `cd`.
- **File and Directory Management:** Using commands like `mv`, `cp`, `mkdir`, and `rmdir`.
- **File Search:** Using `find`, `which`, and other search utilities.
- **Redirection and Filtering:** Working with streams and commands like `grep`, `tail`, and `head`.
- **User Management:** Creating, modifying, and managing user permissions.
- **Services and Process Management:** Managing Linux services and processes with `systemctl`, `apt`, and `dpkg`.
- **Task Scheduling:** Automating tasks with cron jobs and other scheduling tools.
- **Web Services Setup:** Using tools like `npm` and `PHP` for basic server setup.
- **File System Management:** Exploring storage structures and handling disk-related tasks.

### Windows Fundamentals
- **System Architecture:** Understanding core components of the Windows operating system.
- **User Management:** Creating and managing user accounts and permissions.
- **File Systems:** Navigating, securing, and analyzing Windows file systems.
- **Security Practices:** Identifying and mitigating vulnerabilities within Windows environments.
- **Command-Line Tools:** Utilizing PowerShell and Command Prompt for administrative tasks.

## Purpose
These reports aim to:
1. Document step-by-step solutions for HackTheBox challenges.
2. Provide a reference for cybersecurity professionals and enthusiasts.
3. Enhance practical skills in analyzing and securing Linux and Windows systems.

## Highlights
- Practical scenarios with screenshots for step-by-step solutions.
- Application of key cybersecurity tools and techniques.
- Real-world relevance for ethical hacking and system administration.
